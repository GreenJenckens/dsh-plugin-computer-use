## Automated coverage (new)

- overlay windows are filtered from `windows.list` and rejected as explicit targets;
- sensitive keyword click is denied by default and allowed with
  `__allowConsequential`;
- ask mode: bridge writes `confirm-request.json`, a simulated human writes
  `confirm-response.json`, the pending action executes;
- cancel flag rejects the next host operation and clears on resume;
- existing 44 tests remain green.

## Limits

- Confirmation is on-desktop, not tamper-proof: the model can blind-click dialog
  coordinates in principle; overlay is hidden from selectors, not pixels. Use a
  VM/DSH approval policy for strict boundaries.
- Primary monitor only; no multi-monitor glow.
- No full takeover (hand mouse to human and back); hotkey pauses/resumes.
- Keyword matching is heuristic; configurable via `confirmKeywords`.
