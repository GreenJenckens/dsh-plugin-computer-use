## Added

### Stale-safe refs
`observe.tree` now emits `ref=<8 hex>` next to `i=`. A ref is a compact hash of
`hwnd|role|name|nth|auto`; `act.*`/`observe.*` re-resolve it against a fresh UIA
tree on every call. A closed window or a changed role/name/autoId/nth fails with
`stale ref …`, not a click at old coordinates. `i=` remains per-walk.

Live: `observe.tree title="DeepSeek Harness"` returned
`ref=f9614a02 i=2 Pane …`; `observe.info ref=f9614a02` re-resolved the same row.
Automated stale test: tree → ref → `act.click` works; close window → same ref
fails with `stale ref`.

### Takeover pill / indicator redesign
- 700×104 blue gradient pill at top center, rounded 22 px, title + hint + white
  **Остановить** button; clicking it pauses/resumes (same as `Ctrl+Alt+Shift+Q`).
- Paused state turns the pill/ring red and the button becomes **Продолжить**.
- Edge effect reduced from 10 px + 26 px to a 3 px line + 18 px low-opacity glow
  (no harsh rectangle).
- Cursor marker is a thin ring (4 px) with a 6 px center dot instead of the old
  thick 36 px donut; no magenta transparency fringe.
- Still 15 s idle + smooth fade, click-through `DSH-CU-*` windows.

### CDP browser lane
Config `cdpPort` (optional). `browser.list` reads loopback `/json/list`;
`browser.eval` runs `Runtime.evaluate` over the page WebSocket.

Live: headless Edge `--remote-debugging-port=9223` →
`browser.list` returned `id=… title="about:blank" url=about:blank ws=yes`;
`browser.eval text='location.href + "|" + (1+1)'` returned `about:blank|2`.
`browser.eval` is opt-in and arbitrary page JS; `browser.list` is allowed in
`readonly`, `browser.eval` is not.

## 21 tools — considered, not adopted

`computer-user` exposes 21 separate tools; each has its own schema/description
and can be permissioned individually. We kept one dispatcher because:

- one tool carries **44 actions / 48 params** at 3.2 KB compact — more action
  surface than 21 tools, but one fixed schema instead of 21;
- a single `mode`/subagent/confirm gate covers every action;
- no duplicate tool-selection ambiguity or per-tool context cost;
- `act.sequence` already batches calls.

A `surface: "multi"` facade is possible later, but it would duplicate wrappers
and gates for no capability gain.

## Limits

- Confirm dialog remains on-desktop, not tamper-proof.
- No transparent mouse-handoff takeover.
- Stable refs are per-bridge-process; a bridge restart asks for a fresh
  `observe.tree` (loudly, via `stale ref`).
- CDP requires a browser started with `--remote-debugging-port`; it is arbitrary
  page JS and should be opt-in.
- 2 monitors / 125–150% remain mathematically validated only.
- OCR report-only (CER 16% ru / 23.65% en; 0→D=0 at scale 2/3).
